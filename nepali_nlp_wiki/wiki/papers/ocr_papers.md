# Devanagari Optical Character Recognition (OCR) Research Literature

## Overview
Optical Character Recognition for Nepali involves parsing the continuous horizontal header line (*Shirorekha*), disjoining touching conjuncts, and recognizing upper/lower vowel diacritics (*matras*).

## Key Publications

- **Guha et al. (2019)**: *DevNet: An Efficient CNN Architecture for Handwritten Devanagari Character Recognition*.
  - *Contribution*: Specialized Convolutional Neural Network architecture achieving high accuracy on complex conjuncts and modifier vowels.
- **Bal & Rupakheti (2007)**: *Research Report on the Nepali OCR*.
  - *Landmark*: The original foundational technical investigation at Kathmandu University establishing Tesseract adaptations and Shirorekha-removal algorithms for Nepali print documents.
- **Pant et al. (2012 / 2015)**: *Deep Learning Based Large Scale Handwritten Devanagari Character Recognition*.
  - *Contribution*: Creation of standardized character benchmarks and deep belief network baselines for isolated character recognition.
