# Regex & Text Cleaning

## Core Patterns
- Character classes, quantifiers, anchors
- Capturing groups and backreferences
- Lookahead / lookbehind

## Text Cleaning Pipeline
1. Lowercasing
2. Remove HTML / special chars
3. Normalize unicode (important for Devanagari!)
4. Whitespace normalization
5. Stopword removal (domain-dependent)

## Python Tools
- `re` module
- `unicodedata` for normalization
- `ftfy` for encoding fixes
