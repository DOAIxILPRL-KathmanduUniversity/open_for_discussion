# Textual Code-Switching

> [!IMPORTANT] Gist
> Code-switching is the practice of alternating between two or more languages or dialects in a single conversation or text. In NLP, this poses significant challenges for language identification, POS tagging, and MT (Garg et al., 2024).

## 1. Theoretical Types
- **Intersentential**: Switching at sentence boundaries.
- **Intrasentential (Code-Mixing)**: Switching within a sentence or clause.
- **Tag-Switching**: Inserting a tag or short phrase from one language into another.

## 2. Measuring Complexity
- **CMI (Code-Mixing Index)**: Quantifies the level of mixing in a corpus.
- **Integration Index**: Measures how deeply one language is integrated into the structure of another.

## 3. NLP Techniques for Code-Switching
- **Language Identification**: Identifying which language is used at the word or sub-word level.
- **POS Tagging**: Handling mixed syntax where a verb from Language A might take an affix from Language B.
- **Machine Translation**: Translating code-switched text into a single target language (e.g., "Hinglish" to English).

## 4. Applications
- **Social Media Analysis**: Monitoring sentiment in informal multilingual communities.
- **Education**: Analyzing code-switching in teaching environments.
