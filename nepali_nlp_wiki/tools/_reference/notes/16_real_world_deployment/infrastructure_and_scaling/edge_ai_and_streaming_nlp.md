# Edge AI & Streaming NLP

> [!IMPORTANT] Gist
> Real-time NLP applications (like healthcare monitoring or retail analytics) require low-latency processing. This is achieved through Edge/Fog computing and streaming analytics platforms (Raj et al., 2024).

## 1. Edge, Fog, and Cloud Computing
- **Edge Computing**: Processing data at the source (e.g., IoT sensors).
- **Fog Computing**: An intermediate layer between the Edge and the Cloud for local aggregation and filtering.
- **Cloud Computing**: Heavy-duty processing and long-term storage.

## 2. Streaming Analytics
- **Messaging Systems**: Using platforms like **Kafka**, **RabbitMQ**, or **ActiveMQ** to handle high-velocity data streams.
- **Architecture**:
    - **Producers**: IoT sensors, log generators.
    - **Brokers**: Messaging middleware.
    - **Consumers**: NLP models for sentiment analysis, anomaly detection, or summarization.

## 3. Industry Use Cases
- **Healthcare**: Real-time monitoring of patient health indices (e.g., during COVID-19) using wearable data.
- **Retail**: Analyzing customer sentiment and behavior in real-time to optimize inventory and marketing.
