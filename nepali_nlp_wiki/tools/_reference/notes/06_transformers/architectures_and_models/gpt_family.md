# GPT Family

## GPT-1 (Radford et al., 2018)
- Decoder-only transformer
- Unsupervised pre-training + supervised fine-tuning

## GPT-2 (2019)
- 1.5B parameters, zero-shot learning
- "Too dangerous to release" narrative

## GPT-3 (2020)
- 175B parameters, few-shot in-context learning
- Prompt engineering becomes a skill

## GPT-4+ (2023+)
- Multimodal (text + vision)
- RLHF alignment
- Tool use and function calling

## Key Insight
- Autoregressive: P(x_t | x_1, ..., x_{t-1})
- Scale + data + compute = emergent abilities
