# Perplexity

## Definition
- PP(W) = P(w₁w₂...wₙ)^{-1/n}
- Lower perplexity = better model
- Geometric mean of inverse probabilities

## Intuition
- "How surprised is the model by the test data?"
- Equivalent to 2^{cross-entropy}

## Practical Notes
- Only comparable with same vocabulary
- Not always correlated with downstream task performance
- Standard metric for language model evaluation
