# Automated Scoring & Educational Assessment

> [!IMPORTANT] Gist
> NLP-based automated scoring utilizes computational linguistics to evaluate human responses (text and speech) in educational settings. It balances accuracy with psychometric principles like validity and fairness (Yaneva & von Davier, 2023).

## 1. Automated Scoring Paradigms
- **Classical Approach**: Expertly crafted features (grammar, syntax, length) mapped to scores using statistical models.
- **Deep Learning Approach**: End-to-end scoring where features are learned by multilayered neural networks (RNNs, LSTMs, Transformers).
- **Content Scoring**: Using concept matching between a student response and a rubric (e.g., scoring patient notes in medical exams).

## 2. Psychometric Considerations
- **Validity**: Ensuring the automated score measures the intended construct (e.g., writing proficiency) and not construct-irrelevant noise.
- **Fairness**: Ensuring the scoring engine does not penalize specific subgroups (demographics, dialects).
- **Interpretability vs. Accuracy**: Deep learning models are often "black boxes." Testing organizations must decide if they need interpretable models or if high predictive accuracy is sufficient.

## 3. Educational Applications
- **Automated Item Generation (AIG)**: Using AI to generate test items (multiple-choice, reading passages) from paragraphs.
- **Stealth Assessment**: Embedding assessment within games or interactive environments (e.g., iSTART).
- **Automated Writing Evaluation (AWE)**: Providing feedback and scoring for student writing to improve retention and achievement.
