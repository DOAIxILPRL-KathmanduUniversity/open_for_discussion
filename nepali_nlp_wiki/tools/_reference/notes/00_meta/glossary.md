# 📖 Glossary

| Term | Definition |
|------|-----------|
| **Corpus** | A large collection of texts used for training or analysis |
| **Token** | A single unit of text (word, subword, or character) |
| **Vocabulary** | The set of all unique tokens in a corpus |
| **Embedding** | A dense vector representation of a word or token |
| **Attention** | A mechanism that lets models focus on relevant parts of input |
| **Fine-tuning** | Adapting a pre-trained model to a specific task |
| **Perplexity** | A metric measuring how well a language model predicts text |
| **NER** | Named Entity Recognition — identifying entities in text |
| **POS** | Part-of-Speech — grammatical category of a word |
| **BPE** | Byte Pair Encoding — a subword tokenization algorithm |
| **TF-IDF** | Term Frequency–Inverse Document Frequency |
| **RAG** | Retrieval-Augmented Generation |
| **Seq2Seq** | Sequence-to-Sequence — encoder-decoder architecture |
| **BLEU** | Bilingual Evaluation Understudy — MT evaluation metric |
| **ROUGE** | Recall-Oriented Understudy for Gisting Evaluation |
